# 📈 DGS Takip Asistanı (DGS Tracking Assistant)

## 🇹🇷 Proje Hakkında (TR)

**DGS Takip Asistanı**, Dikey Geçiş Sınavı (DGS) hazırlık sürecimde çalışma performansımı ölçmek, günlük hedeflerimi takip etmek ve motivasyonumu artırmak amacıyla geliştirdiğim **konsol tabanlı (CLI)** bir araçtır.

Bu proje, Python öğrenme sürecimdeki **ilk projem** olup; algoritma mantığı, dosya işlemleri ve veri yapıları konularını pekiştirmek amacıyla geliştirilmiştir.

### 🚀 Özellikler
* **Ders ve Soru Ekleme:** Günlük çalışılan ders ve soru sayısı girişi.
* **Görsel İlerleme Çubuğu:** Hedefe ne kadar yaklaşıldığını gösteren dinamik Progress Bar.
* **Otomatik Tarih Loglama:** `datetime` kütüphanesi ile girişlerin otomatik tarihlenmesi.
* **Veri Kalıcılığı (File Handling):** Tüm çalışmaların `gunluk_kayit.txt` dosyasına kaydedilerek saklanması.
* **Hedef Analizi:** Günlük hedefin altında veya üstünde kalma durumuna göre akıllı geri bildirimler.

---

## 🇬🇧 About The Project (EN)

**DGS Tracking Assistant** is a CLI-based tool developed to track daily study progress, manage goals, and boost motivation during the preparation for the Vertical Transfer Exam (DGS).

As my **first Python project**, this tool was built to practice core concepts such as algorithms, data structures, and file handling.

### 🚀 Features
* **Data Entry:** Input daily subjects and question counts.
* **Visual Progress Bar:** ASCII-based dynamic progress bar to visualize goals.
* **Auto Date Logging:** Automatic timestamping using the `datetime` library.
* **Data Persistence:** Saves all logs to a `gunluk_kayit.txt` file for record-keeping.
* **Goal Analysis:** Provides feedback based on daily target achievement.
